2. About the app

The App is an Android application for practising university-entrance exams. The project README documents question-bank import, full mock exams, custom quizzes, national-exam presets, statistics, printing, offline mathematics rendering, a local study planner, and 13 interface languages. Most study features work offline. Optional online features include scheduled complete exams, results, student lookup and rankings, question-bank sharing, announcements, an educational directory, and teacher/organization publishing tools.

The README states that the App is distributed through GitHub Releases and an in-app updater and is not currently on Google Play. Features and availability may vary by version and backend configuration.

3. Educational use and results

The App is a practice and study aid. It does not guarantee admission, examination performance, academic results, or the accuracy or completeness of every imported question or explanation. Practice scores are not official results. According to the README, official online exam submissions are scored by the server; local practice is separate and does not create an official result.

Exam presets and structures are intended to help organise practice. The README notes that some preset structures are owner-specified or checked against guides rather than an official bulletin. Users should verify current exam requirements with the relevant examination authority.
