Privacy Policy

How Kankor VIP (Kankor VIP) handles information in the Android app and this website.

Effective date: October 24, 2026

1. Introduction

This policy describes the information practices documented for Kankor VIP (the “App”), an Android application for practising university-entrance exams, and this website, which provides app information and legal documents. The app's README describes most study features as offline-first, with an optional online area powered by Supabase. The actual features enabled in a particular build and the services' current configurations may affect what information is processed.

2. Privacy at a glance

  • Question banks, exam practice, scoring, statistics, printing, the study planner, settings, and received banks are designed to work locally without an account or internet connection.
  • If you choose online features, information associated with your account/profile, submitted exam answers, question banks you share, and content you publish may be sent to the Supabase backend.
  • Signing in is supported using an email one-time code or Google sign-in through a system browser.
  • AI helper tools hand selected question content to an AI app already installed on your device; the README says the App makes no in-app model calls and uses no AI API keys.
  • The README does not document advertising or analytics SDKs. This statement is based on the README and is not an independent dependency or network-traffic audit.

3. Information stored on your device

According to the project README, the App stores question banks, imported material, exam attempts and statistics in its local database, settings in local app storage, and study plans and frozen exam attempts on the device. This information supports features such as offline practice, results review, statistics, printing, and reminders. The README says the Supabase session is excluded from Android backup and device transfer.

Question-bank files are imported by the user. The README says the repository includes a 16-question demonstration bank and no complete-exam content. Material you choose to import may contain information supplied by you or another author; consider that before sharing a bank online.

4. Optional online features and account information

The App's optional online area uses Supabase. The documented features include scheduled complete exams, official exam participation and results, student lookup and rankings, question-bank sharing, announcements, an educational directory, and teacher/organization publishing tools. You do not need to use these online features to use the documented offline study tools.

When you use these features, information sent to the server may include your account and student profile, answers submitted for official exams, question banks you choose to share, and content you publish. The App supports email one-time-code sign-in and Google sign-in using a system browser and a PKCE return flow. The project README states that the server enforces country isolation, official exam timing, scoring, ranking, and result publication. The exact server-side retention periods and account-deletion process are not publicly specified in the project documentation. For requests about account data, contact the developer using the address below. Deleting local app data does not necessarily delete information already sent to the server.

5. Third-party services

Supabase: Used for optional online features and authentication. Information sent through those features is processed by the backend and its infrastructure providers under their applicable terms and privacy practices.

Google sign-in: If you choose Google sign-in, authentication takes place through Google's sign-in flow in the system browser. Google's own terms and privacy policy also apply to Google's processing.

GitHub: The App checks GitHub Releases for updates without credentials, according to the README. The README describes distribution through GitHub Releases and an in-app updater, and says the App is not currently on Google Play. GitHub's own terms and privacy practices apply to its services.

The project documentation does not describe an in-app advertising service, analytics provider, or crash-reporting SDK. This has not been independently verified against every dependency or network request.

6. AI helper features

The App can open an AI application already installed on your device when you ask about a question or request help creating questions. The README says the prompt may include the question, answer options, correct answer, and any available explanation; question-generation prompts can also include options and study metadata you provide. The App copies prompts to an AI app and may import a copied JSON response from the clipboard. It does not make in-app model calls according to the README.

If you choose to use an external AI service, the information you send is handled by that service under its own terms and privacy policy. Avoid sending personal or confidential information in prompts unless you have considered the external provider's practices.

7. Permissions, reminders, and updates

The README lists these Android permissions: internet and network-state access; package-install permission for the updater; notifications; vibration; boot-completion access; exact-alarm scheduling; and foreground-service/media-playback permissions. Notifications and alarms support the local study planner. The updater checks GitHub Releases. The README says downloads use the system file picker and that the App does not request storage permission. It also says cleartext traffic is disabled and that the manifest queries only four AI apps.

8. Sharing and disclosure

Local question banks and study records are designed to remain on the device unless you use a feature that sends information elsewhere. If you choose to share a question bank, participate in an official online exam, sign in, or publish content, the information needed for that feature may be transmitted to the backend and processed or shown according to that feature's operation. Information sent to Google, GitHub, or an external AI app is also subject to the relevant provider's policies. The project documentation does not describe selling personal information. This statement reflects available project documentation and is not a guarantee about third-party providers' independent practices.

9. Retention and deletion

Local records remain in app storage until they are removed through available app data-management features or the app's data is otherwise removed from the device. The README documents local data management, including bank deletion and resetting results. The exact retention periods for account profiles, submitted online exam answers, shared banks, and published content on the Supabase backend are not specified in the README and must be confirmed by the developer. Do not assume deleting local app data also deletes server-side information.

10. Security

The README describes a backend security model with server-enforced country isolation, official timing, scoring, ranking, and result publication; it also states that the app contains no service-role key, invitation-code list, or answer keys. It says cleartext traffic is disabled and the Supabase session is excluded from Android backup and device transfer. No system can be guaranteed completely secure, and the README alone cannot verify the current deployment, configuration, or every security control.

11. Children's privacy

The App is an educational exam-practice tool, but the README does not specify a minimum age or state whether it is directed to children under the relevant legal definitions. The app is an educational study tool. If you believe a child has provided personal information through an online feature, contact the developer so the circumstances can be reviewed.

12. Your choices

You can use the documented offline study features without signing in or using the optional online area. You can choose whether to use online exams, share question banks, publish content, sign in with Google, or send content to an external AI app. The App's local data-management features include bank deletion and resetting results. The process for accessing or deleting server-side account data must be confirmed by the developer and described here before final publication.

13. Changes to this policy

This policy should be updated when the App's data practices or connected services materially change. The developer should publish a revised version with an accurate effective date and provide any notice required by applicable law.

14. Contact

For privacy questions or requests, contact the app developer at amirialigoll@gmail.com. This address should be monitored so users can receive a response. For account-data requests, contact the developer at the address below and describe the account and request. The developer may need to verify your identity before acting. The availability and scope of deletion depend on the records and backend capabilities involved.
